Rodney — one browser, many commands

Every rodney invocation is a short-lived process. state.json is the rendezvous that reconnects each one to the same persistent headless Chrome — cookies, localStorage and tabs survive.

the rendezvous

state.json holds debug url, pid, active_page — each command reconnects through it. A second start overwrites it and orphans the live browser: guard with rodney status || rodney start.

exit codes 0 / 1 / 2

0 success · 1 assertion failed (retry candidate) · 2 error — bad args, timeout, no browser (fix, don't retry).

always stop

rodney stop when done, or Chrome runs forever. rodney-ps --json lists managed vs orphan processes; rodney-cleanup --clean kills orphans non-interactively.

ROD_CHROME_BIN

go-rod's bundled Chromium is a frozen 2024 dev snapshot. If text returns "" or type never lands, point ROD_CHROME_BIN at your system Chrome.
