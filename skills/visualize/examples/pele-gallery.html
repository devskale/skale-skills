02sequence — the share flow

From build to rendered page, end to end.

      sequenceDiagram
        participant A as Agent
        participant V as visualize gate
        participant S as throway store
        participant B as Your browser
        A->>V: gate page.html
        V-->>A: validate + slop + chartcheck + jscheck · all pass
        A->>S: share (PUT, stable URL)
        S-->>A: URL
        A->>B: open URL
        B->>B: fetch pele from CDN (~230 kB gzip)
        B->>B: render() each block · 0.05–0.3 ms
        B-->>B: SVG themed from the page's own tokens
