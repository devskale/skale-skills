# Reviewed — external skills & repos

Reviews of external skills/repos we looked at in depth. A review here is a **record,
not a recommendation**: it captures what the thing does, whether it is worth adopting,
and what (if anything) is worth stealing — so we never have to re-review it from scratch.

> **Status convention:** every file opens with its status:
>
> ```markdown
> Status: **reviewed — not adopted** (or: **adopted**, **rejected**)
> ```
>
> A review never triggers an install (hard rule, AGENTS.md → External Skills).
> Adoption only on explicit user request.
