skill flow · surf

Your real Chrome, driven from the shell

surf speaks to the Chrome you are logged into — bookmarks, cookies, sessions included — through macOS AppleScript. No daemon, no debug port, no extension, and no per-connection “Allow remote debugging?” dialog.

The path a command takes

        flowchart LR
          A[Agent] --> C[surf CLI · 30+ commands]
          C --> O[osascript · Apple Events]
          O --> CH[your logged-in Chrome]
          CH --> R([text · JSON · screenshot])
          CH --> R([text · JSON · screenshot])
          R --> C
          C --> A

What makes it painless

No debug port

Chrome 136+ ignores --remote-debugging-port on the default profile. surf never needed it — AppleScript is the native lane.

No dialogs, no daemon

One-time “Allow JavaScript from Apple Events”, then commands run quietly — read background tabs without stealing focus.

CI-ready output

surf assert exits 1 on mismatch, --json for machines — the same commands work interactively and in scripts.
