The three paths

Zero-config default

Public SearXNG works out of the box — text, images, news, video. Private instance: credgoo searx.

Token upgrade

Duck API unlocks --site --filetype --inurl --exclude --exact for text queries.

Always SearXNG

Media categories never leave SearXNG, token or not. Force a lane with --api / --searxng.
